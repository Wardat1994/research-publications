# Research Publications
Research publications in robotics, control systems, kinematics, singularity avoidance, and intelligent control.

## Mohammad Yasin Al-Wardat
**Ph.D. Candidate | Robotics and Control Systems Researcher**

This repository presents my research publications in robotics, robotic manipulator kinematics, singularity avoidance, obstacle avoidance, motion planning, intelligent control, and mechatronic systems.

### Research Areas
- Robotic Manipulator Kinematics
- Forward and Inverse Kinematics
- Jacobian Analysis
- Singularity Detection and Avoidance
- Obstacle Avoidance
- Real-Time Motion Planning
- Damped Least Squares (DLS)
- Redundancy Resolution
- Fuzzy Logic and Intelligent Control
- MATLAB, Python, Arduino, and Robotics Toolbox
